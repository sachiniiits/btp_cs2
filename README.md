# btp_cs2
Built an end-to-end behavioural analytics pipeline ingesting raw CS2 .dem replay files from IEM Katowice 2025 &amp; StarLadder Budapest Major 2025, classifying per-player per-round roles (Entry / AWPer / Support / Lurker / IGL) with no labelled training data across 120 matches (∼36,000 player-rounds).
